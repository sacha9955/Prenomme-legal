❓ Questions fréquentes

L'app fonctionne-t-elle hors-ligne ?
Oui, totalement. Tous les prénoms sont stockés dans l'application.

Comment passer à la version Pro ?
Réglages → "Passer à Pro", ou en tapant n'importe quelle fonctionnalité Pro verrouillée.

Comment restaurer mes achats sur un nouvel appareil ?
Réglages → "Restaurer les achats" (avec votre Apple ID).

Comment résilier un abonnement ?
Réglages iOS → votre Apple ID → Abonnements → Prénomme Pro → Annuler.

Mes favoris sont-ils synchronisés entre mes appareils ?
Oui, automatiquement via iCloud (si vous êtes connecté avec le même Apple ID).

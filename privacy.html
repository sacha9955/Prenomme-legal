Politique de confidentialité

Dernière mise à jour : 28 avril 2026 — Version 1.0

Prénomme respecte votre vie privée. Cette politique explique quelles informations sont traitées par l'application iOS « Prénomme » (ci-après « l'Application »), comment elles sont utilisées, et vos droits.

2. Données traitées

Prénomme est conçue avec une approche privacy-first. L'Application ne collecte et ne transmet aucune donnée personnelle vers des serveurs distants contrôlés par l'éditeur.

2.1 Données stockées localement sur votre appareil

2.2 Synchronisation iCloud (optionnelle)

Si vous activez la synchronisation iCloud dans les Réglages iOS, vos favoris sont synchronisés via CloudKit (service Apple) entre vos appareils. Ces données restent dans votre compte iCloud personnel, chiffrées par Apple, et ne sont jamais accessibles à l'éditeur.

3. Données collectées par Apple (achats intégrés)

Lorsque vous achetez Prénomme Pro (à vie, mensuel ou annuel), la transaction est gérée par Apple via StoreKit. L'éditeur reçoit uniquement :

  • Une confirmation anonymisée de l'achat (ID transaction)
  • Des rapports financiers agrégés via App Store Connect

L'éditeur n'a accès ni à votre Apple ID, ni à votre adresse email, ni à votre carte bancaire. La politique de confidentialité d'Apple s'applique : apple.com/legal/privacy.

4. Données NON collectées

L'Application ne collecte pas :

  • Pas de compte utilisateur ni de connexion
  • Pas d'identifiant publicitaire (IDFA)
  • Pas de localisation
  • Pas de données analytiques tierces (pas de Firebase, Google Analytics, etc.)
  • Pas de cookies, pas de pixels de tracking
  • Pas de données de santé, contacts, photos, micro, ou caméra

5. Tiers

L'Application n'intègre aucun SDK tiers de tracking ou d'analyse. Les seules dépendances externes sont :

  • Apple StoreKit — gestion des achats (obligatoire iOS)
  • Apple CloudKit — synchronisation iCloud optionnelle (uniquement si activée par l'utilisateur)
  • GRDB — bibliothèque locale pour la base de données SQLite (open-source, ne communique avec aucun serveur)

6. Données des prénoms

La base de données des prénoms est embarquée dans l'application (fichier local SQLite). Sources :

  • INSEE — Fichier des prénoms 2024 (licence ouverte Etalab 2.0)
  • SSA (Social Security Administration, États-Unis) — Données publiques
  • Wikidata — Licence CC0
  • Étymologies générées et vérifiées par l'éditeur

7. Droits (RGPD)

Comme aucune donnée personnelle n'est collectée par l'éditeur, les droits RGPD s'exercent directement depuis votre appareil :

  • Accès — toutes vos données sont visibles dans l'app (favoris, historique)
  • Suppression — désinstallez l'app pour effacer toutes les données locales ; videz votre conteneur iCloud depuis Réglages iOS → Apple ID → iCloud → Gérer le stockage du compte → Prénomme
  • Portabilité — utilisez la fonction « Export PDF » (Pro) pour récupérer vos favoris

8. Sécurité

Les données sont stockées dans le sandbox de l'application protégé par iOS. Les données iCloud sont chiffrées par Apple en transit et au repos.

9. Enfants

L'application a une classification 4+ et ne collecte aucune donnée. Elle peut être utilisée par toute personne, y compris dans un contexte familial.

10. Modifications

Cette politique peut évoluer. La version en vigueur est toujours celle accessible à sacha9955.github.io/prenomme-legal/privacy.html. La date de dernière mise à jour figure en haut du document.
